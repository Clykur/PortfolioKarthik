## Core Stack

- **Frontend & Mobile**: React, React Native, Expo, TypeScript, TailwindCSS
- **Backend & Infrastructure**: Node.js, Supabase, PostgreSQL, Docker, Vercel
- **Tooling**: Vite, TypeScript, ESLint, PostCSS

## Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
